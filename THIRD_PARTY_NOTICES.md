## Project Nayuki QR Code generator 1.8.0 — tests only

- Upstream: https://github.com/nayuki/QR-Code-generator/tree/v1.8.0
- Location: `tests/vendor/qrcodegen.cpp` and `qrcodegen.hpp`.
- Copyright (c) Project Nayuki. MIT License. Full notice and permission text are retained in both files.
- This independent encoder generates known test fixtures and is not compiled into `qrvector`.

The example JPEG/PNG inputs are generated test fixtures encoding `https://example.com`; they are not user data. The committed SVGs are produced by `./qrvector` from that grid, with two- and four-module margins. Application and example versions/defaults are documented in the root README and `examples/README.md`.
