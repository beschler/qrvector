# Example assets

All examples encode the public test URL `https://example.com` and share the same original version 3, 29×29 module grid, mask 4, and ECC M. The reference encoder is used only by the test fixture generator; the qrvector executable never generates a new QR.

| File | Purpose | Margin per side | Canvas |
| --- | --- | ---: | ---: |
| `example.jpg` | JPEG input with compression artifacts | 4 modules | 629×629 px |
| `example.png` | Lossless PNG input with the same grid | 4 modules | 629×629 px |
| `example.svg` | Default transparent SVG output | 2 modules | 561×561 px |
| `example-margin-4.svg` | Transparent SVG with the standard quiet zone | 4 modules | 629×629 px |

The black QR body is 493×493 source pixels in every variant: 29 modules × 17 pixels/module. Only the surrounding margin changes between SVGs; the black module pattern stays identical.

From the project root:

```sh
./qrvector examples/example.jpg -o examples/example.svg --force
./qrvector examples/example.jpg -o examples/example-margin-4.svg --margin 4 --force
# These two commands are also available as: make examples
```

Converting `example.png` with the default margin produces the same `example.svg` geometry and bytes. The JPEG is 50,664 bytes; both SVG variants are 1,573 bytes, a 96.9% reduction. PNG savings differ because the source is already compressed differently.

SVG light modules and margins are transparent. Display them on a uniform light background; the two-module default alone is below the standard four-module quiet zone. SVG viewers may antialias vector edges without storing gray pixels in the SVG.

The committed raster sources are deterministic reference fixtures generated by `tests/test.cpp`. To regenerate source fixtures after an intentional fixture change, run `make test`, copy `build/fixtures/example.jpg` and `build/fixtures/example.png` into this folder, then run `make examples` and update any measured sizes in documentation. Normal `make examples` only refreshes the SVGs.
